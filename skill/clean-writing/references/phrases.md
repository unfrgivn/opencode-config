# Phrases to Remove or Replace

## Throat-Clearing

Cut these and start with the point:

- "Here's the thing"
- "Here's what/why/how"
- "The truth is"
- "The reality is"
- "It turns out"
- "Let me be clear"
- "It's worth noting"
- "At its core"
- "When it comes to"
- "In today's landscape"
- "In this section, we'll"
- "This document will"

## AI Tells and Filler

Delete unless the word carries real meaning:

- really
- just
- simply
- actually
- basically
- broadly
- deeply
- truly
- fundamentally
- inherently
- importantly
- crucially
- notably
- significantly
- meaningful
- robust
- seamless
- comprehensive
- leverage
- unlock
- drive alignment

## Business Jargon

| Avoid | Use instead |
| --- | --- |
| navigate challenges | handle problems |
| unpack | explain, examine |
| lean into | accept, use |
| landscape | situation, market, codebase |
| game-changer | important change |
| double down | commit, invest |
| deep dive | analysis, review |
| moving forward | next, from now |
| circle back | revisit |
| on the same page | aligned |
| stakeholders | teams, reviewers, customers, named people |
| utilize | use |

## Vague Claims

Replace broad claims with facts, examples, or uncertainty labels:

- "The implications are significant"
- "The stakes are high"
- "This is a complex problem"
- "This creates alignment"
- "This improves visibility"
- "This unlocks value"
- "This provides a better experience"

Better patterns:

- "This cuts deploy time from 20 minutes to 8 minutes."
- "Support cannot debug failed imports without database access."
- "Assumption: paid search data arrives within 24 hours."

## Performative Emphasis

Remove lines that try to sound quotable:

- "Full stop"
- "Period"
- "Let that sink in"
- "Make no mistake"
- "And that's okay"
- "That's the point"
- "The rest is noise"
